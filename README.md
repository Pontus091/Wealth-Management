# Wealth-Management
This project is a self-directed learning build exploring how wealth management tools work under the hood. It pulls historical market data, calculates core portfolio metrics (returns, volatility, correlation, Sharpe ratio), compares model portfolios, and maps a simple client risk profile to a suggested allocation. Later stages add rebalancing, fee-aware backtesting, and Monte Carlo simulations for savings goals.
Disclaimer: This is an educational simulation. It does not provide personalized investment advice, and past performance does not guarantee future results.
